# 章节职责与段落处理记录

基线：`339d51e`（v0.9.2）。本次整理保留 16 章和原始实验记录。章节标题不再决定每次重排后的小节编号；[原公开小节](section-baseline.json)与[当前固定编号](../course/section-ids.json)分别保存，迁移定位写入 [catalog.json](../course/catalog.json) 的 `sectionRedirects`。

## 每章只承担一个主要教学任务

| 章 | 核心问题 | 必要前置 | 主讲概念与边界 |
| --- | --- | --- | --- |
| 01 请求 | “你好”之外还有哪些输入？ | 导读的项目与样本范围 | 消息、角色、内容块和用户输入来源；不展开 Hook、流式协议与用量计算 |
| 02 工具 | 谁读取 README，正文何时到达模型？ | 请求与输出 | 工具定义、调用、返回和 call_id；历史引用仅解释本轮必要衔接 |
| 03 Agent Loop | 多次工具往返如何完成修复？ | 能配对一次调用和返回 | 新信息推动下一步、修复验收；保留五次请求和最终文件证据 |
| 04 会话 | 同一任务与新任务得到哪些历史？ | 一轮可以含多次请求 | 历史重发、响应引用、任务归属；不根据 token 大小判断记忆 |
| 05 上下文 | 历史变长后怎样继续工作？ | 历史的两种接续方式 | 摘要、替换历史、后续使用、缓存和用量；不提前教规则/技能字段 |
| 06 AGENTS | 项目约定怎样进入请求并影响回答？ | 消息来源、文件读取 | 规则装配与效果；Hook 留在第 10 章 |
| 07 Skills | 技能何时被发现、加载与执行？ | 规则与工具 | 目录、显式正文、工具读取和行为；不重复工具包装通识 |
| 08 记忆 | 新任务怎样取得旧决定？ | 新旧任务的历史差异 | 文件笔记与原生提取、整合、召回对照，保留未测试边界 |
| 09 MCP | 商品单价怎样从服务返回？ | 一次工具往返 | 能力发现、服务调用与可复现实现 |
| 10 Hooks | 运行事件何时注入、拦截和观察？ | 规则、技能与工具 | 配置、信任、三个事件时机及其局限 |
| 11 权限 | 提出的写入为什么被拒绝？ | 工具动作与结果 | 沙箱、审批、真实拒绝；不提前展开完整计划实验 |
| 12 Plan | 尚有歧义的需求怎样进入实施？ | 执行边界 | 调查、澄清、计划与确认实施；文字进度仅作区别 |
| 13 多 Agent | 两份独立检查怎样交回父任务？ | 上下文、工具与计划 | 委派、继承、独立结果、汇集 |
| 14 运行状态 | 怎样判断继续、停止或恢复？ | 工具结果和完成条件 | Goal、文字进度、失败、中断、后台句柄、补丁恢复 |
| 15 流式输出 | 文本片段怎样成为完整回答？ | 请求、工具调用和修复结果 | delta、输出项、响应完成与空 output 的样本区别 |
| 16 架构 | 应向哪个组件、哪份记录找证据？ | 前述各机制 | 职责和证据范围；不再逐项复述同一次修复验收 |

## 内部样章检查

先整理 01–03 章，由另一位审阅者核对完整 diff。确认角色与来源、call_id、R0–R4 的因果链和修复验收仍完整，才推广到后续章节。新增练习对照 06-tests 的真实调用与返回；没有新增或改写实测结果。

## 数据与界面边界

- 原始 `evidence/`、历史截图及 `examples/` 保留。工作台新增定位提示，但完整记录、复制、分享和下载继续可用。
- `readingGuide` 为每章提供起点、观察任务与准确证据目标；不复制完整正文。请求日期和模型名来自记录，缺失的环境版本明确不推定。
- 术语解释复用 `GLOSSARY.md`；全站搜索定位正文与折叠段落，不搜索历史提示词作为课程答案。
- `PROGRESS.md` 的个人掌握记录不由编辑或页面浏览自动更新。
