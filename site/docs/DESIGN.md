## 路由与证据定位

`#/` 为首页，`#/guide` 为导读，`#/lesson/<id>` 为单章阅读。旧 `#/lesson/introduction` 及原 20 个章节地址保留映射；实验、请求阶段、视图、文件种类和输入项位置等参数继续传递。

章节正文中的请求来源链接定位对应实验和阶段，输出链接进入模型输出，原始事件与清单保留完整文件入口。使用哈希路由适配 GitHub Pages 的 `/agent-harness-notes/` 子路径，资源与许可链接也按该部署根路径解析。

## Agent Loop 时间线

第 3 章以 `evidence/desktop-lab/07-fix` 的真实五次请求为唯一运行数据源。用户输入、每次模型请求、提出的调用、交回的结果和最终回复各有对应来源。工具结果位于后续请求，使用实际 `call_id` 配对；不能把调用提出时点当作执行已经完成。

阶段说明属于教学讲解，原始文本和标识保留在可展开区及工作台。时间线只在这一章提供，不将演示步骤伪装成新的模型运行，也不向其他章节自动填充推测事件。

## 验证

`npm run check` 检查 15 个主题、前后导航、归档链接、JSON、26 组实验与 74 个请求阶段。构建后的浏览器检查以 `/agent-harness-notes/` 子路径提供网站，核对首页卡片、导读与单章路由、刷新与旧书签、本章目录、折叠说明、复制分享、截图资源、许可文件和移动端布局。

证据工作台继续逐项比较输入、角色、内容块、输出、完成事件、流式事件和 CPA 两侧快照。时间线额外核对五份请求、四次调用与下一请求的真实返回，并实际打开相应链接。视觉检查覆盖首页、章节、时间线、手机和深色主题。
