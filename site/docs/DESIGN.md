## 阅读与导航

开篇来自 `course/introduction.md`，包含运行架构；第一节展示真实 Desktop 截图。20 篇正文保留独立 Markdown 文件和原有 `#/lesson/<id>` 地址，在网站中变为同一长文的段落跳转。左侧目录列出四阶段和20节，展开当前节的段落锚点；全文搜索直接过滤对应章节。

正文采用旧版的 15px、1.7 倍行高和无衬线字体。标题、段落、源码、实验控件明确分层；手机端目录可收起，源码和表格独立滚动。固定页头不遮挡开篇及段落标题。真实截图由 Vite 管理资源路径，点击可在新标签打开原尺寸文件，不重新绘制或裁改 UI。

Mermaid 图表按 SVG 的原生宽度呈现，超出正文时只在图框内横向滚动，不缩小标签字号。图表使用 neutral 主题和固定浅背景，切换阅读主题后仍保持对比度。

## 内嵌工作台

每节正文后都有工作台，可选择该节关联的实验和全部请求，包括预热。进入视口或显式选择时才加载证据。主要视图为：

- **输入与工具定义**：按 `input` 原数组顺序显示所有项目及实际 `role`。每个 `content` 块可独立展开完整文字；`additional_tools`、调用结果及其他非消息类型均保留。工具定义在真实字段位置呈现，不补造不存在的顶层 `tools` 或 `instructions`。
- **模型输出**：按流式事件导出的输出项顺序阅读消息、工具调用及其他输出。每项完整 JSON 可展开，包含实际记录的 summary、metadata 和已脱敏字段。明确标注这是衍生视图，原始完成事件未被回填或改写。
- **工具调用与结果**：全局按 `call_id` 关联已收录模型输出与后续请求，支持跨实验的中断恢复。外层工具脚本不被虚构成独立调用；未找到关联时只说明公开证据缺口。
- **客户端 / 上游**：并排展示两个完整快照，按 JSON 字段和值判断是否相同。不得借用历史样本的转发差异解释当前记录。
- **原始记录**：可选择请求、衍生输出、完成事件、流式事件、上游、压缩、中断和实验来源文件，支持全文复制与下载。

工作台显示本次与前次 response ID，并从全部实验建立响应跳转。分享链接保留章节、实验、请求、视图及原始文件种类。正文中的来源链接就地打开对应工作台或补充文件区域，不依靠证据弹窗。

父任务委派、原生压缩、原生计划没有普通输入或最终回复时，页面显示对应记录说明。中断任务明确显示“已中断”，不将单次 `response.completed` 当作整个用户任务完成。

## 完整性与数据边界

折叠只影响展示，不删除或截断源文本；全文可展开、滚动、复制，原项目 JSON 始终可核对。复制注册随被替换的工作台内容释放，避免反复查看大 JSON 时累积过时字符串。异步切换使用请求版本和路由标记，旧结果不会覆盖新视图或抢回滚动位置。

内容和证据分别来自 `course/`、`evidence/desktop-lab/`；历史 `lessons/01-codex-cpa-trace/` 的 JSON 保留但不编入新站。Markdown 经 marked 解析和 DOMPurify 清理。`verified` 与 `partial` 说明证据覆盖范围，不代表读者掌握状态；原生 Memories 的生成和召回仍保留未实测边界。

## 验证入口

`npm run check` 核对课程、链接、JSON、响应引用与示例行为。`npm run build` 完成后运行 `node scripts/check-site.mjs`：遍历索引中每个实验的全部 stage，逐项比较完整输入、角色、内容块、原项目、输出、完成事件及两侧快照，验证跨实验链接、复制和分享。

同一检查还覆盖开篇标题位置、源码字号、Mermaid、真实图片资源、补充来源、中断、压缩、三种屏宽、搜索和移动目录，并要求没有浏览器或控制台错误。显式添加 `--capture-readme` 才更新 `docs/images/site-preview.png`；普通检查只写 `work/` 截图。
