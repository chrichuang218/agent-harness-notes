## 模型输出文字

**我的初步建议：以 harness 工程为主线，按项目需要补 TS，不必先完整学完 TS 语法。** 前提是你已经能用某种语言写简单程序。我这里把 harness 理解为 Agent 的运行框架，包括模型调用、工具执行、状态管理和评测。

原因是：TS 解决“代码怎么表达”，harness 解决“Agent 怎么可靠地运行”。如果你的目标是做 Agent，真实项目更容易暴露你到底缺哪些基础；代价是开始时会频繁停下来补知识。

本阶段可以这样取舍：

- **主线**：理解并修改一个最小 Agent harness。
- **TS 学到够用**：能读懂函数、对象、类型、模块和 `async/await`，能独立修改相关代码。
- **暂缓**：高级类型体操、完整框架源码和复杂多 Agent 架构。
- **第一阶段验收**：能解释一次“模型调用 → 工具执行 → 结果回传”，独立改一个行为，并验证结果。只靠 AI 生成后跑通，还不足以证明掌握。

**如果你目前连函数、对象、异步调用都不熟，顺序就要调整：先补最小编程基础，再进入 harness。**

你目前更接近哪种情况：完全没写过程序、会其他语言但不熟 TS，还是已经能写一些 TS？
